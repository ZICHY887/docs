IMAGES
======

Put your screenshots in THIS folder. The docs page looks for these exact
filenames and shows them automatically. Anything missing is skipped cleanly,
so you can add them one at a time.

FILENAMES THE PAGE EXPECTS
--------------------------
  hero.png      Wide banner. Your best effect on a real clip. ~1600x700.
  step-1.png    The Custom category with the + button visible.
  step-2.png    The file picker with an .xml file selected.
  step-3.png    The thumbnail prompt (the image picker that appears
                right after a successful import).
  step-4.png    The effect applied to a layer.
  editor.png    Your text editor with an effect file open.

TIPS
----
* PNG or JPG both work. Keep each under ~400 KB so the page stays fast.
* Phone screenshots are fine - the layout scales them to the column width.
* Want an extra slot? Copy an existing
  <figure class="shot" data-img="IMAGES/x.png"> block in index.html
  and change the filename.

IF A SCREENSHOT DOESN'T SHOW
----------------------------
Check the filename matches exactly (lowercase, .png) and that the file is
really inside this IMAGES folder, not a subfolder.
